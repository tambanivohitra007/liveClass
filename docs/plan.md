# Quiz Analytics Workbook -- Worksheet Descriptions

## 1️⃣ Overview

### Description:

This sheet contains **question-level performance analysis**.

It includes: - Question number and text\
- Question type (e.g., Multiple Choice)\
- Module/Standard\
- Question accuracy (%)\
- Average time per question\
- Summary statistics: - Correct - Incorrect - Unattempted - Partially
correct - Individual student answers (each student has their own column)

### Purpose:

Used to analyze: - Which questions were easy or difficult\
- Student answer patterns\
- Overall performance per question

This is the **core academic performance analysis sheet**.

------------------------------------------------------------------------

## 2️⃣ Participant Data


### Description:

This sheet contains **student-level performance summary**.

It includes: - Rank\
- Student ID / Name\
- Total questions attempted\
- Accuracy (%)\
- Score\
- Correct / Incorrect counts\
- Total time taken\
- Device/browser info\
- Start time

### Purpose:

Used to: - Rank students\
- Evaluate overall performance\
- Identify top performers\
- Compare accuracy and time

This is the **leaderboard + summary statistics sheet**.

------------------------------------------------------------------------

## 3️⃣ Time Data


### Description:

This sheet contains **per-question response time per student**.

It includes: - Question number\
- Question text\
- Question accuracy\
- Average time per question\
- Individual student response times

### Purpose:

Used to: - Analyze speed vs accuracy\
- Detect very fast guessers\
- Identify slow/difficult questions\
- Study behavioral patterns

This is the **time analytics sheet**.

------------------------------------------------------------------------

## 4️⃣ Quiz Details


### Description:

This sheet contains **quiz metadata**.

It includes: - Game start time\
- Game type (Instructor-paced quiz)\
- Other configuration/session information

### Purpose:

Used to: - Document quiz settings\
- Identify quiz mode\
- Track session information

This is the **quiz configuration sheet**.

------------------------------------------------------------------------

# Overall Structure Interpretation

This Excel file contains a complete analytics export of a quiz system
with:

1.  Question analytics (Overview)\
2.  Student ranking + summary (Participant Data)\
3.  Response time analytics (Time Data)\
4.  Session metadata (Quiz Details)

It is well-structured for: - Academic analysis\
- Performance auditing\
- Statistical review\
- Detecting anomalies (e.g., unusual speed patterns)
